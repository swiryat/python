# Education Materials

This folder contains curated Python educational materials for learners and practice.

## Structure

- `advanced python/` — advanced Python topics, examples, and task notebooks.
- `data science/` — data science practice notebooks and examples.
- `task/` — programming tasks and challenge notebooks.

## Notes

- The notebooks are intended for study and hands-on learning.
- Interactive `input()` calls have been commented out where present to improve compatibility with automated review tools.
- A helper script `cleanup_education.py` is included at the repository root for maintenance.
